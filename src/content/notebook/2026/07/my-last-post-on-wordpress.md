This is my last post on my WordPress website. There is no point in tarrying. I must set a target for myself and get this over the line.

With my Astro website rewrite steadily progressing, I see no reason to hang about here. I will make the switch on Saturday, 1 August. That should give me plenty of time to port over all the remaining data, to set up redirects, and to archive a static HTML version of this site somewhere.

As part of the new setup, my RSS feed will change. If you're reading this on your feed reader, please update the feed URL to https://thamara.co.uk/notebook/rss.xml.

This website will no longer be updated. WordPress has been great to me for 12 years, but now it's time for a new adventure. Something I've created myself from the ground up. Many things will break, and will stay broken for a while, but I have made my peace with that.
