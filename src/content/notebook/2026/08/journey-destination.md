If you've ever visited my [changelog](/changelog), you'd know that this website gets built almost every day; several times a day on most days. It's not just because I've been blogging regularly this month. Things get changed around a lot. Fixes, tweaks, overhauls. It's never ending. I have a [Trello](https://trello.com/) board full ideas for what I want to do with this website. I've made peace with the fact that I'll never get through all of it.

Yesterday I added this disclaimer to my homepage:

>This website will always remain a work in progress, and you will frequently see things that are half-built, or simply broken.

Leaving things broken doesn't bother me anymore. On previous versions of the website, I had [sought the help of LLMs](/notebook/2026/05/location-and-weather-in-now) to add features I wanted to add but didn't have the technical chops to build. It is convenient, but deeply unsatisfying.

Here are just a few things I want to add, but have no idea how to build:

1. Location and weather information on my [now](/now) page—the same feature I employed Google Gemini to build on my previous site

2. Search

3. Sending Webmentions

4. Blog stats

Some of these features may require learning new programming languages, something I simply do not have the time to commit to. I may be able to find shortcuts—such as bits of code shared by kind netizens who have already solved these problems—for some things, which I may be able to adapt without understanding how the underlying technology works (which is how I have written all the JavaScript and TypeScript required for this Astro build). Some may never get built.

But finding the [joy](https://indieweb.org/joy) in what I *can* do with my limited knowledge is what I'll focus on. IndieWeb is a journey, not a destination, I've decided.
